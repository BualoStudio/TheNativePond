**《本水塘》** 者，乃 **象外工坊（Beyond Pixels Studio）** 所筑，以疗愈心神、不慕荣利为旨之独立游艺也。 

方今之世，游者苦于案牍之劳（日常打卡）、品阶之累（通行证）、较力之苦（数值碾压）与探囊之忧（抽卡焦虑）久矣。吾辈愿辟一温柔乡以作抗言——**罢黜簿册、不较毫厘、蠲免差役**。此一拳之石，一勺之水，无血气之限，无勇武之评，亦无必达之期。且驻足于此，**复还嬉游之本心**。

## ✨ 游艺本要

《本水塘》摒弃“信手拈来”之浮躁法门。吾辈取人间真实之触感，以纤毫无差之流仪，复刻于大道至简之画卷中。

### 🎣 宛若亲临之垂钓真趣

此绝非轻按机枢即可得鱼之俳戏，吾辈倾力还原本真之垂钓心流：

- **亲和钓饵**：君须至肆中购得奇饵，观天象，察水情，度量注水，揉捏醒发，更兼打窝布阵，步步考究。  
- **屏息以待**：悬饵抛竿，静观水波微荡，端视浮标沉浮。相机而动，方能一击必中。  
- **沧海遗珠**：偶有上钩者，非锦鳞游鱼，乃时代之“藏品”也。  

### 🍳 尽享人间烟火之烹调

丝竹之外，更兼庖厨之乐。其烹调之法，与尘世无二，令太虚幻境亦生人间烟火之气：

- **细理烹调之序**：欲求一碗阳春面？须采买麦粉，临案注水，揉面醒发，亲手擀制。  
- **调和鼎鼐之功**：汲水发薪，静候鼎沸而后下锅。诸般繁文缛节皆不可省，唯此方可察五谷成馔之确幸。  
- **随心所欲之大厨**：君可循规蹈矩依“食单”而作，亦可天马行空随意杂糅。或成绝世珍馐，或成暗黑鸩毒，此间唯存野趣，了无责罚。  

### 🎨 大道至简之丹青美学

- **泼墨大写**：洗净铅华，尽弃雕饰，唯以纯粹之 SVG 矢量色块割裂太虚。  
- **涤除玄览**：无满目疮痍之机枢按键，无阿堵铜臭之所。画卷清朗克制，独留一泓清泉。  
- **坐忘灵台**：非线性之幻象令池水宛如“吐纳”，于漫漫静候之中，还光阴于灵台。

## 🛠️ 营造法式与基底

为求轻灵曼妙、通达各界且便于同好共襄盛举，本阵列采用如下基底：

- **枢机之本**：筑基于 **TurboWarp** 平台与 **Icyphantom 框架** 之上。  
- **敷彩之法**：HTML5 原生敷彩，极尽轻巧，纵劣器亦能流转如飞。  
- **丹青格式**：繁多画录皆赖可缩放矢量图形（SVG），保其广狭纵横之间，锋芒毕露，不失其真。

## 🤝 同襄共举

《本水塘》非唯吾等独占之物，更期为天下倦客之“避风长亭”。不论足下是否深谙机要代码，皆可为斯塘添砖加瓦！

吾辈翘首以盼如下呈文（Issue）：  
1. **拾遗投名**：为斯戏赋感怀之辞一句，或共话一段镌刻岁月之旧梦。  
2. **献曝乡味**：拟就全新食单一张（如：古法热干面之炮制），并详叙其庖丁之步。  

> [!TIP]
> 入局之前，务请展阅吾等之 [贡献指南](https://github.com/BeyondPixelsStudio/TheNativePond/CONTRIBUTING.md)，并恪守 [行为准则](https://github.com/BeyondPixelsStudio/TheNativePond/CODE_OF_CONDUCT.md)。

> [!NOTE]
> 缘于 TurboWarp 独卷之限，切勿径向源本递呈献书（Pull Request）。然足下可将缺漏（Bug）投于 [呈文 (Issue)](https://github.com/BeyondPixelsStudio/TheNativePond/issues) 之中。
