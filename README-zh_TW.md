**《本水塘》** 是由 **Beyond Pixels Studio (像素之外)** 開發的一款治癒系非營利性獨立遊戲。 

當下，玩家們正被困在無盡的“日常打卡”、通行證等級、數值輾壓和抽卡焦慮中。我們希望打造一次溫柔的反抗——**無簽到打卡、無數值強度、無任務副本**。這是一個沒有體力條、沒有戰鬥力評分、甚至沒有強制目標的小池塘。在這裡，**重拾對遊戲的熱愛**。

---

## ✨ 核心體驗與玩法

《本水塘》拒絕“點擊即得”的快餐化設計。我們將生活中的真實觸感，透過 1:1 的擬真流程還原到了極簡的畫面之下。

### 🎣 1:1 沉浸式擬真垂釣

這絕非一個按空白鍵就能把魚拉上來的街機小遊戲，我們致力於還原真實的垂釣心流：

- **親手開餌**：你需要在遊戲內的雜貨舖購買基礎餌料，根據天氣和目標水域，一步步按比例加水、揉搓、醒餌、打窩。  
- **擬真等待**：掛餌、拋竿，觀察水面漣漪的細微變化與浮標的下沉動作，把握提竿的最佳時機。  
- **特殊藏品**：有時釣上來的並非魚，而是“藏品”。  

### 🍳 充滿煙火氣的自由烹飪

垂釣之外，遊戲內建了與現實步驟完全一致的烹飪系統，讓賽博空間充滿生活的實感：

- **硬核的步驟拆解**：想吃一碗陽春麵？你需要先買麵粉，在砧板上親手加水、和麵、醒發、擀麵條。  
- **火候與時間**：接水、開火，耐心等待水沸騰後再下鍋煮。每一個步驟都不可省略，感受食物在手中逐漸成型的踏實感。  
- **絕對自由的烹飪**：你可以嚴格遵循“菜譜”，也可以無視一切規則隨心搭配食材。無論是驚喜的美味還是黑暗料理，這裡只有樂趣，沒有懲罰。  

### 🎨 極致的極簡視覺美學

- **大色塊與扁平化**：摒棄多餘的紋理，使用純粹的 SVG 向量色塊分割畫面。  
- **去 UI 化設計**：沒有滿螢幕的按鈕和儲值入口，畫面乾淨克制，將螢幕徹底交給水面。  
- **純粹的放空**：非線性動畫讓池水微微“呼吸”，在漫長的等待中，把時間還給你的大腦。

## 🛠️ 技術棧與架構

為了確保輕量化、跨平台以及便於社群的介入，本專案採用了以下技術基礎：

- **底層引擎**：基於 **TurboWarp** 平台與 **Icyphantom 框架** 建構。  
- **渲染方案**：HTML5 原生渲染，極致輕量，流暢運行於各類低階設備。  
- **資產格式**：大量美術資產均採用可縮放向量圖形 (SVG)，確保在任何解析度下的邊緣銳度。

## 🤝 參與共建

《本水塘》不僅僅是我們的作品，我們希望它能成為所有疲憊玩家的“公共休息區”。無論你是否懂程式碼，都可以為這個池塘添磚加瓦！

我們極其歡迎以下形式的 Issue：  
1. **記憶碎片投遞**：為遊戲撰寫一句動人的文案，或分享一段具有時代感的舊回憶。  
2. **家鄉菜譜貢獻**：設計一份全新的食譜（例如：如何做一碗正宗的熱乾麵），並拆解它的現實步驟。  

> [!TIP]
> 參與前，請務必閱讀我們的 [貢獻指南](https://github.com/BeyondPixelsStudio/TheNativePond/CONTRIBUTING.md) 並遵守 [行為準則](https://github.com/BeyondPixelsStudio/TheNativePond/CODE_OF_CONDUCT.md)。

> [!NOTE]
> 由於 TurboWarp 的單一原始檔限制，請不要直接對原始檔提交 Pull Request。但你可以將 Bug 提交到 [Issue](https://github.com/BeyondPixelsStudio/TheNativePond/issues)。
