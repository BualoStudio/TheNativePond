# 信纸

> [!NOTE]
> 这个文件用来存档所有在游戏中出现的信纸。

1. 繁星点缀天空，清风拂过静谧。在这宁静的夜晚中，万千美好自会浮现在心里。
2. 当你开始追光的那一刻，你便成了光。
3. 你好。我不知道你是谁，也没有什么珍贵礼物送给你。但我可以送你一朵小红花，以及一个微笑。要天天开心哦~(◕ᴗ◕✿)！
4. 当一颗流星从天空中坠落时，并不意味着消亡，而意味着它创造了独属于自己的美丽。
5. 等春风，等夏雨，等迎春花开满大地。等鸟声，等虫鸣，等繁星闪烁，夜空的宁静。等下课铃响，人声鼎沸的欢愉，等火车到站，笑与泪的团聚。等烟花的声响划破了雪夜的沉寂，人们互相祝福，紧紧相依。等世间的一切美好降临的那一刻，你我脸上共同露出的笑意。
6. 也许世界上有五千朵和你相同的花，但只有你是那朵独一无二的玫瑰。——《小王子》
7. 幸福是什么？它会调皮地躲在落叶堆里，会在池塘边泛起阵阵涟漪，会在合欢树的芽间生长，会被芳草间的蟋蟀传递，会在五毛钱的冰棍上化开，会从烧烤摊的烟气上升起，会悄悄地藏在你的心底，而出现在每个用心感知的瞬间里。
8. 我独自待在塘边的时候，总会向池塘中倾注自己的低语。或许水面会用它广阔的胸怀，容纳世间的所有思绪。
9. 再美丽的花，也曾只是一棵新芽。所有的美都需要等待，所有的绽放都需要时间。
10. 一片树叶落下时，并没有被春抛弃，而是在演奏秋的乐章。
11. 在时间的长河中，每个个体都是一朵奔腾的浪花，无休无止地奔涌向前。每个人都无法抓住浪花，但记忆可以铭刻浪的声音。
12. 不必为了拥抱蓝天而长出翅膀，也不必为了拥抱大海长出鱼鳍。
13. 人们总是向往天上的太阳，却时常忽略露间的月光。
14. 或许美好并不是没有残缺，而是在残缺中寻找碎片的美。
15. 在塘的对岸，是否有一个人，与我吹着同一阵晚风？
16. 数亿年后，在宇宙的另一端，会不会有一位小孩，躺在草地上，望着一片来自数亿年前的星空，恰恰注视着此时数亿年前的我？
17. 世界上只有一种英雄主义，那就是认清生活的真相后仍然热爱生活。——罗曼▪罗兰
18. 生活仍在继续，太阳仍会照常升起。明天，又是新的一天。
19. 旅人啊，不必为了停滞不前而懊恼，整装待发才能行得更远。
20. 每个人一辈子都有许多不顺心的事，一件完了一件又来。所以丁香结年年都有。结，是解不完的；人生中的问题也是解不完的，不然，岂不太平淡无味了吗？——宗璞《丁香结》
21. 时间会将每一个珍贵的瞬间铭刻下来。就像树的年轮，那是它们生命的纪念。
22. 保持微笑。你看，当你微笑时，这片水塘也在微笑着看你。
23. 浩瀚的宇宙中有不计其数的星星，当你抬头仰望星空时，总有一颗星是独属于你的。
24. 生命本就是在无数个奇迹中创造的。假如有一天，你走到了"绝境"，我相信你一定会书写一段"生命的奇迹"。
25. 如果生活是无意义的，那么不妨让生活每一分每一秒，都由你赋予意义。
26. 不要为了一小片乌云而烦恼。打开视野，等待你的是一整片广阔的天空。
27. 在有些人看来，希望可能只是一盏孤灯。然而，它发出的一丝微光足以在黑夜中指引方向。选择紧握住希望，便是追求光明的第一步。
28. 正是因为有了落差，才有了河流奔腾的壮丽。
29. 未知常常是最使人们担心的事。然而，确定又一成不变的生活，又有什么意思？使生活真正得以为生活的，便是其富有魅力的未知性。
30. 与"一生"这一漫长的时间单位相比，身边的琐屑都只是暂时。不必被一些小事桎梏，未来的路依旧很长。
31. 不必强迫自己开成玫瑰花，每个人都有独属于自己的一份艳丽。
32. 生命来到这世间，经历了数亿分之一或数万亿分之一的巧合。也就是说，你本就是这世间最珍贵的礼物。
33. 主角并不只是在台上绽放光彩的那一个，当你拼尽全力演绎自己的生活时，你同样也是一位耀眼的主角。
34. 至少……夕阳很美，不是吗？
35. 我了解，面对生活的考验，仍然坚持走到今天，是很不容易的一件事。你真的很勇敢。
36. 每个人都有自己得意或失意的时候，就像天上的月亮，有时圆有时缺。然而，圆缺的变化，不正是月亮独特的美丽之处吗？珍惜圆满，也不必苦于缺憾。
37. 人生本就是一场漫无目的的旅行，我们本不必到达目的地，体会旅途本身比追寻旅途的终点更重要。
38. 当蒲公英飞向远方时，它并不知道自己将要去往何方。但无论到哪里，它都会努力生根发芽。
39. 有的时候，对自己宽容一些会更好。没有必要什么时候都表现得很要强，不妨给自己留点空间，把自己拼好。
40. 坦然面对曾经的自己，然后和祂告别。这是成长的一环。
41. 白天的欢笑与泪水，都会在梦里汇成一段新的故事。不妨把昨天抛在梦里，今天又是崭新的一天。
42. 情绪是潮水，它会来，也会走。而你是岸，一直都在这里。
43. 无论发生什么，你心底仍有那20亿个炽热的细胞在为你跳动。
