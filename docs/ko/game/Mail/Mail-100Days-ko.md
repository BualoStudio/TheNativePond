당신은 The Native Pond에서 많은 것을 겪었습니다. 비를 맞은 적도, 비 갠 뒤의 활짝 갠 하늘을 기다린 적도 있었습니다. 오랜 기다림 끝에 미끼를 무는 물고기 한 마리에 설레기도 했고, 혀끝에서 피어난 한 번의 맛있는 순간에 기뻐하기도 했습니다. 때로는 연못가를 서성이며, "시원한 바람이 살랑 불어와도 수면은 잔잔하다"는 고요함을 말없이 바라보았고, 때로는 이곳저곳을 탐험하며 꽃 한 송이 풀 한 포기의 아름다움을 발견했습니다. 때로는 그저 조용히 앉아 명상하며, 지치지만 뿌듯한 하루를 곱씹기도 했습니다.

The Native Pond가 당신에게 백 일의 아름다움을 선사할 수 있었던 것을 영광으로 생각하며, 백 시간의 위로를 드릴 수 있었던 것 또한 영광으로 생각합니다.

어쩌면 다른 세계의 삶은 The Native Pond의 삶처럼 아름답지 않을지도 모릅니다. 하지만 새로운 하루의 해가 떠오를 때, 길가의 꽃이 피어날 때, 맑은 바람이 숲 사이를 스쳐 갈 때, 봄비가 보슬보슬 대지에 내릴 때, 음식의 따뜻함이 입가에 맴돌 때, 길가의 새끼 고양이 한 마리가 삶에 들어올 때, 당신이 포근한 풀밭을 밟을 때, 고개를 들어 밤하늘의 별을 바라볼 때, 나는 당신이 The Native Pond의 아름다움을 떠올리고, 삶의 의욕을 다시 불태우기를 바랍니다.

앞으로 당신은 The Native Pond에 계속 머물지도, 가끔 돌아와 구경할지도 모릅니다. 언젠가 당신이 이 연못을 영영 떠나더라도, 우리는 이 연못에 당신의 이야기가 남아 있었던 것을 기쁘게 여길 것입니다. 하지만 무엇이 되었든, 당신이 필요할 때 The Native Pond는 언제나 이 자리에서 당신을 기다리고 있습니다.
