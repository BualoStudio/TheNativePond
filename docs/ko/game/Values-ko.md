## ✨ The Native Pond의 의미는 무엇인가요?

현실 속에서 사람들은 늘 온갖 임무와 스트레스, 책임에 휩쓸리곤 합니다. 그런 것들은 사람들을 몸과 마음 모두 지치게 만들고, 때로는 방향과 자기 가치를 잃게 만들기도 합니다. 우리는 이 빠른 시대에 누구나 발걸음을 늦출 수 있도록, 물 한 곳을 터 주어야 할 때라고 생각합니다. The Native Pond는 모든 사람의 마음의 피난처입니다. 크지는 않지만, 모든 감정과 마음속 이야기를 담아낼 만큼은 넉넉합니다. 그래서 우리는 The Native Pond를 유토피아로 정의합니다. The Native Pond에서는 좋지 않은 일은 존재하지도, 일어나지도 않습니다. 이곳은 평화와 사랑, 희망을 실어 나르는 주유소입니다. **The Native Pond가 존재하는 의미는, 누구나 현실의 어떤 어려움과 좌절, 아픔을 마주할 때 이곳에서 잠시 쉬고 치유받은 뒤, 더욱 충만한 마음가짐으로 다시 삶을 마주할 수 있게 하는 것입니다.** 게임은 플레이어에게 끊임없이 "이것은 단지 게임일 뿐이다"라고 상기시킵니다. 그 목적은 플레이어가 The Native Pond에 지나치게 빠져 현실 세계를 도피하고 거부하지 않도록 하기 위함입니다.

## 👟 The Native Pond는 어떻게 운영되나요?

우리는 오늘날의 게임 대부분이 매일 출석 체크, 퀘스트 시스템, 던전 반복 플레이 같은 지루하고 재미없는 콘텐츠로 가득 차 있다는 것을 발견했습니다. 우리는 플레이어에게 매일 오랜 시간 접속하고 고강도의 반복 조작을 강요하는 이러한 장치들이 이미 게임의 본래 취지를 어겼다고 생각합니다. 게임은 플레이어가 즐기고 쉬기 위한 수단이어야지, 게임 회사가 플레이어를 착취하는 돈벌이 도구가 되어서는 안 됩니다. 이를 위해 The Native Pond 제작팀은 약속합니다: **이 작품은 프로젝트의 소스 코드를 오픈소스화하고, 전 플랫폼에 무료로 배포하며, 게임 내에 어떤 광고도 포함하지 않고, 어떤 형태의 유료 DLC나 마이크로트랜잭션도 포함하지 않습니다.** 우리는 플레이어에게 필요한 것은 진정한 고품질 게임이며, 단기적인 이익만 쫓고 플레이어의 마음을 돌보지 않는 조악한 제품이 아니라고 믿습니다.
