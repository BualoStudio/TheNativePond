# 특별 감사

- [@Minecraft](https://minecraft.net)  
	- Minecraft는 *The Native Pond* 제작팀의 등대이자, 우리가 본보기로 삼는 존재입니다.  
	- Minecraft는 *The Native Pond*의 자유를 최우선으로 하는 개발 이념에 방향을 제시해 주었습니다.  

- [@Farmer's Delight](https://www.curseforge.com/minecraft/mc-mods/farmers-delight)  
	- Farmer's Delight는 *The Native Pond*의 힐링, 느긋한 속도 같은 이념에 길잡이가 되어 주었습니다.  
	- Farmer's Delight의 단계별 음식 만들기 등 많은 설정이 *The Native Pond*의 관련 설정에 영감을 주었습니다.
