# 信紙

> [!NOTE]
> 這個檔案用來存檔所有在遊戲中出現的信紙。

1. 繁星點綴天空，清風拂過靜謐。在這寧靜的夜晚中，萬千美好自會浮現在心裡。
2. 當你開始追光的那一刻，你便成了光。
3. 你好。我不知道你是誰，也沒有什麼珍貴禮物送給你。但我可以送你一朵小紅花，以及一個微笑。要天天開心哦~(◕ᴗ◕✿)！
4. 當一顆流星從天空中墜落時，並不意味著消亡，而意味著它創造了獨屬於自己的美麗。
5. 等春風，等夏雨，等迎春花開滿大地。等鳥聲，等蟲鳴，等繁星閃爍，夜空的寧靜。等下課鈴響，人聲鼎沸的歡愉，等火車到站，笑與淚的團聚。等煙花的聲響劃破了雪夜的沉寂，人們互相祝福，緊緊相依。等世間的一切美好降臨的那一刻，你我臉上共同露出的笑意。
6. 也許世界上有五千朵和你相同的花，但只有你是那朵獨一無二的玫瑰。——《小王子》
7. 幸福是什麼？它會調皮地躲在落葉堆裡，會在池塘邊泛起陣陣漣漪，會在合歡樹的芽間生長，會被芳草間的蟋蟀傳遞，會在五毛錢的冰棍上化開，會從燒烤攤的煙氣上升起，會悄悄地藏在你的心底，而出現在每個用心感知的瞬間裡。
8. 我獨自待在塘邊的時候，總會向池塘中傾注自己的低語。或許水面會用它廣闊的胸懷，容納世間的所有思緒。
9. 再美麗的花，也曾只是一棵新芽。所有的美都需要等待，所有的綻放都需要時間。
10. 一片樹葉落下時，並沒有被春拋棄，而是在演奏秋的樂章。
11. 在時間的長河中，每個個體都是一朵奔騰的浪花，無休無止地奔湧向前。每個人都無法抓住浪花，但記憶可以銘刻浪的聲音。
12. 不必為了擁抱藍天而長出翅膀，也不必為了擁抱大海長出魚鰭。
13. 人們總是嚮往天上的太陽，卻時常忽略露間的月光。
14. 或許美好並不是沒有殘缺，而是在殘缺中尋找碎片的美。
15. 在塘的對岸，是否有一個人，與我吹著同一陣晚風？
16. 數億年後，在宇宙的另一端，會不會有一位小孩，躺在草地上，望著一片來自數億年前的星空，恰恰注視著此時數億年前的我？
17. 世界上只有一種英雄主義，那就是認清生活的真相後仍然熱愛生活。——羅曼·羅蘭
18. 生活仍在繼續，太陽仍會照常升起。明天，又是新的一天。
19. 旅人啊，不必為了停滯不前而懊惱，整裝待發才能行得更遠。
20. 每個人一輩子都有許多不順心的事，一件完了一件又來。所以丁香結年年都有。結，是解不完的；人生中的問題也是解不完的，不然，豈不太平淡無味了嗎？——宗璞《丁香結》
21. 時間會將每一個珍貴的瞬間銘刻下來。就像樹的年輪，那是它們生命的紀念。
22. 保持微笑。你看，當你微笑時，這片水塘也在微笑著看你。
23. 浩瀚的宇宙中有不計其數的星星，當你抬頭仰望星空時，總有一顆星是獨屬於你的。
24. 生命本就是在無數個奇蹟中創造的。假如有一天，你走到了"絕境"，我相信你一定會書寫一段"生命的奇蹟"。
25. 如果生活是無意義的，那麼不妨讓生活每一分每一秒，都由你賦予意義。
26. 不要為了一小片烏雲而煩惱。打開視野，等待你的是一整片廣闊的天空。
27. 在有些人看來，希望可能只是一盞孤燈。然而，它發出的一絲微光足以在黑夜中指引方向。選擇緊握住希望，便是追求光明的第一步。
28. 正是因為有了落差，才有了河流奔騰的壯麗。
29. 未知常常是最使人們擔心的事。然而，確定又一成不變的生活，又有什麼意思？使生活真正得以爲生活的，便是其富有魅力的未知性。
30. 與"一生"這一漫長的時間單位相比，身邊的瑣屑都只是暫時。不必被一些小事桎梏，未來的路依舊很長。
31. 不必強迫自己開成玫瑰花，每個人都有獨屬於自己的一份豔麗。
32. 生命來到這世間，經歷了數億分之一或數萬億分之一的巧合。也就是說，你本就是這世間最珍貴的禮物。
33. 主角並不只是在台上綻放光彩的那一個，當你拼盡全力演繹自己的生活時，你同樣也是一位耀眼的主角。
34. 至少……夕陽很美，不是嗎？
35. 我了解，面對生活的考驗，仍然堅持走到今天，是很不容易的一件事。你真的很勇敢。
36. 每個人都有自己得意或失意的時候，就像天上的月亮，有時圓有時缺。然而，圓缺的變化，不正是月亮獨特的美麗之處嗎？珍惜圓滿，也不必苦於缺憾。
37. 人生本就是一場漫無目的的旅行，我們本不必到達目的地，體會旅途本身比追尋旅途的終點更重要。
38. 當蒲公英飛向遠方時，它並不知道自己將要去往何方。但無論到哪裡，它都會努力生根發芽。
39. 有的時候，對自己寬容一些會更好。沒有必要什麼時候都表現得很要強，不妨給自己留點空間，把自己拼好。
40. 坦然面對曾經的自己，然後和祂告別。這是成長的一環。
41. 白天的歡笑與淚水，都會在夢裡匯成一段新的故事。不妨把昨天拋在夢裡，今天又是嶄新的一天。
42. 情緒是潮水，它會來，也會走。而你是岸，一直都在這裡。
43. 無論發生什麼，你心底仍有那20億個熾熱的細胞在為你跳動。
