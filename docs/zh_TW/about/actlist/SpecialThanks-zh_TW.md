# 特別感謝

- [@Minecraft](https://minecraft.net)  
	- Minecraft 是《本水塘》製作組的燈塔，它是我們的學習榜樣。  
	- Minecraft 為《本水塘》自由至上的開發理念提供了指引。  

- [@Farmer's Delight](https://www.curseforge.com/minecraft/mc-mods/farmers-delight)  
	- Farmer's Delight 為《本水塘》治癒系、慢節奏等理念提供了引導。  
	- Farmer's Delight 中的逐步製作美食等許多設定均為《本水塘》的相關設定帶來了靈感。
