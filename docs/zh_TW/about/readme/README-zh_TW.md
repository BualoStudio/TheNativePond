**本水塘** 是由 **Bualo Studio（浮標工作室）** 開發的一款非營利性治癒系遊戲。

當下，玩家們正被困在無盡的日常打卡、通行證等級、數值碾壓和抽卡焦慮中。我們希望讓玩家回歸到對遊戲最初的熱愛，而不是將遊戲視為一種需要按時簽到打卡的負擔。所以，我們的遊戲——**無簽到打卡、無數值強度、無任務副本**。這是一個沒有體力條、沒有戰鬥力評分、甚至沒有強制目標的小池塘。在這裡，**重拾對遊戲的熱愛**。

## ✨ 核心體驗與玩法

《本水塘》拒絕「點擊即得」的快餐化設計。我們將生活中的真實觸感，透過擬真的流程還原到了極簡的畫面之下。

### 🎣 沉浸式擬真垂釣

這絕非一個按空白鍵就能把魚拉上來的街機小遊戲，我們致力於還原真實的垂釣玩法：

- **親手開餌**：你需要在遊戲內的雜貨鋪購買基礎餌料，根據天氣和目標水域，一步步按比例加水、揉搓、醒餌、打窩。
- **擬真等待**：掛餌、拋竿，觀察水面漣漪的細微變化與浮標的下沉動作，把握提竿的最佳時機。
- **特殊藏品**：有時釣上來的並非魚，而是「藏品」。

### 🍳 充滿煙火氣的自由烹飪

垂釣之外，遊戲內建了與現實步驟完全一致的烹飪系統，讓賽博空間充滿生活的實感：

- **硬核的步驟拆解**：想吃一碗陽春麵？你需要先買麵粉，在砧板上親手加水、和麵、醒發、擀麵條。
- **火候與時間**：接水、開火，耐心等待水沸騰後再下鍋煮。每一個步驟都不可省略，感受食物在手中逐漸成型的踏實感。
- **絕對自由的烹飪**：你可以嚴格遵循「食譜」，也可以無視一切規則隨心搭配食材。無論是驚喜的美味還是黑暗料理，這裡只有樂趣，沒有懲罰。

### 🥬 休閒放鬆的種田時光

遊戲還提供種田的玩法，讓每個玩家都能親手開闢出一片小天地：

- **播種**：到了適宜農作物生長的季節，你便可開墾出一片田地，播下種子、澆水、施肥，為作物生長提供滋養。
- **生長**：當環境適宜時，作物便會茁壯生長。無需過多打理，只需偶爾關注，讓種田生活變得輕鬆而有樂趣。
- **收穫**：作物成熟時，你可以收穫作物。並非簡單點一點的快速收集，而是模擬真實的採摘/收割流程，讓你切實體會到收穫的喜悅與成就感。

### 🎨 極致的極簡視覺美學

- **大色塊與扁平化**：摒棄多餘的紋理，使用純粹的 SVG 向量色塊分割畫面。
- **去 UI 化設計**：沒有滿螢幕的按鈕和儲值入口，畫面乾淨克制，將螢幕徹底交給水面。
- **純粹的放空**：非線性動畫讓池水微微「呼吸」，在漫長的等待中，把時間還給你的大腦。

## 🛠️ 技術棧與架構

為了確保輕量化、跨平台以及便於社群的參與，本專案採用了以下技術基礎：

- **底層引擎**：基於我們專為《本水塘》打造的 [**小冰島**](https://github.com/BualoStudio/Icelet) 遊戲引擎開發。

> [!WARNING]
> 由於不可抗力因素，小冰島現已終止開發，我們正在尋找新的遊戲引擎或技術實現方法來為本水塘提供技術支援。詳情請閱讀小冰島終止開發公告：[《突然的完結，就像青春一樣》](https://github.com/BualoStudio/Icelet/releases/tag/TheEnding)。

- **渲染方案**：HTML5 原生渲染，極致輕量，流暢執行於各類低階裝置。
- **資產格式**：大量美術資產均採用 SVG 格式，確保在全解析度下的邊緣銳度。

## 🤝 參與共建

《本水塘》不僅僅是我們的作品，我們希望它能成為所有疲憊玩家的「精神加油站」。無論你是否了解遊戲開發或程式碼，都可以為這個小池塘添磚加瓦！

> [!TIP]
> 參與前，請務必閱讀我們的 [**貢獻指南**](https://github.com/BualoStudio/TheNativePond/blob/main/.github/CONTRIBUTING.md) 並遵守 [**行為準則**](https://github.com/BualoStudio/TheNativePond/blob/main/.github/CODE_OF_CONDUCT.md)。

我們極其歡迎以下形式的 Issue：

1. **記憶碎片投遞**：為遊戲撰寫一句動人的文案，或提交一段具有時代感的回憶性短文。
2. **家鄉食譜貢獻**：設計一份全新的食譜（例如：如何做一碗正宗的熱乾麵），並拆解它的製作步驟。
3. **提交遊戲存在的問題**：報告遊戲在特定情況下觸發的問題、漏洞和錯誤，甚至解決方案。

## 🌐 本地化

[**本地化支援情況**](https://github.com/BualoStudio/TheNativePond/blob/main/docs/zh_TW/about/l10nteam/LocalizationSupportStatus-zh_TW.md) 列出了目前受官方支援的語言和支援情況。

我們希望《本水塘》能被全世界的玩家體驗。如果你想幫助將遊戲翻譯成你的語言：

1. Fork 本倉庫。
2. 找到語言檔案（在 `/lang/` 目錄下）。
3. 新增或更新翻譯。
4. 提交 [**Pull Request**](https://github.com/BualoStudio/TheNativePond/pulls)。

> [!TIP]
> 本水塘的本地化工作是由眾多像你一樣的志願者提供的，請查看我們的 [**本地化致謝名單**](https://github.com/BualoStudio/TheNativePond/blob/main/docs/zh_TW/about/l10nteam/LocalizationTeam-zh_TW.md)。

> [!TIP]
> 由於我們的開發週期和精力/資源分配等多方面問題，我們無法保證翻譯100%準確。由於我們沒有專門的本地化團隊，所以部分語言可能是由AI或機器翻譯得到的，其翻譯未必準確無誤，如果您在遊玩過程中發現了翻譯問題，請按上述方法 [**提交PR**](https://github.com/BualoStudio/TheNativePond/pulls) 或 [**提交Issue**](https://github.com/BualoStudio/TheNativePond/issues) 。
