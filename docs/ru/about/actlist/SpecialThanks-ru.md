# Особая благодарность

- [@Minecraft](https://minecraft.net)  
	- Minecraft — маяк для команды *The Native Pond*, наш образец для подражания.  
	- Minecraft указал *The Native Pond* путь к философии разработки, где свобода превыше всего.  

- [@Farmer's Delight](https://www.curseforge.com/minecraft/mc-mods/farmers-delight)  
	- Farmer's Delight подсказал *The Native Pond* идеи исцеления и неспешного темпа.  
	- Многие решения из Farmer's Delight — например, пошаговое приготовление еды — вдохновили соответствующие механики *The Native Pond*.
