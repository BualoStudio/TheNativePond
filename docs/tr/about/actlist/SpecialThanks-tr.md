# Özel Teşekkürler

- [@Minecraft](https://minecraft.net)  
	- Minecraft, *The Native Pond* yapım ekibinin deniz feneridir; bizim için örnek alınacak bir modeldir.  
	- Minecraft, *The Native Pond*'un "özgürlük her şeyden önce" geliştirme felsefesine yol gösterdi.  

- [@Farmer's Delight](https://www.curseforge.com/minecraft/mc-mods/farmers-delight)  
	- Farmer's Delight, *The Native Pond*'a iyileştirici, sakin tempo gibi kavramlarda rehberlik etti.  
	- Farmer's Delight'taki adım adım yemek yapma gibi pek çok mekanik, *The Native Pond*'un ilgili tasarımlarına ilham verdi.
