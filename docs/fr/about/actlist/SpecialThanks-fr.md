# Remerciements spéciaux

- [@Minecraft](https://minecraft.net)  
	- Minecraft est le phare de l'équipe de *The Native Pond* : c'est notre modèle à suivre.  
	- Minecraft a orienté la philosophie de développement de *The Native Pond*, où la liberté prime.  

- [@Farmer's Delight](https://www.curseforge.com/minecraft/mc-mods/farmers-delight)  
	- Farmer's Delight a guidé les valeurs de *The Native Pond*, comme la guérison et le rythme lent.  
	- De nombreux éléments de Farmer's Delight, comme la préparation progressive des plats, ont inspiré les mécaniques correspondantes de *The Native Pond*.
