# Besonderer Dank

- [@Minecraft](https://minecraft.net)  
	- Minecraft ist der Leitstern des Produktionsteams von The Native Pond – es ist unser Vorbild.  
	- Minecraft hat dem Entwicklungsansatz von The Native Pond, bei dem die Freiheit an erster Stelle steht, die Richtung gewiesen.  

- [@Farmer's Delight](https://www.curseforge.com/minecraft/mc-mods/farmers-delight)  
	- Farmer's Delight hat die heilende, langsame Philosophie von The Native Pond geprägt.  
	- Viele Ideen aus Farmer's Delight – etwa das schrittweise Zubereiten von Speisen – haben die entsprechenden Systeme von The Native Pond inspiriert.
