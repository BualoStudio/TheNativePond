方塘玩家鈞鑒：

不知不覺，君於方塘中度過了一百日。

君於方塘中歷事良多：君曾沐雨，亦曾盼得雨後之響晴；君曾因久候之後一魚咬鉤而欣然，亦曾因舌尖綻開之一味而欣喜。時而，君徘徊塘畔，默默凝望那「清風徐來，水波不興」之靜謐；時而，君四處探尋，發掘一花一草之美好；時而，君亦只是靜坐冥思，回味疲憊而滿足之一日。

吾甚榮幸，方塘能為君帶來百日之美；亦甚榮幸，其能予君百時之慰。

或他界之生活，不若方塘之美好；然當新一日之朝陽東升，當路旁之花綻放，當清風穿林而過，當春雨淅瀝落於大地，當食之溫暖迴蕩唇齒之間，當路邊一小貓闖入君之生活，當君踏過鬆軟之草地，當君舉首而見夜穹之星——吾願君能憶起方塘之美好，重燃生活之志。

他日，君或長居方塘，或偶爾歸來一顧。縱他日君將永別方塘，吾輩亦慶幸此塘曾留君之故事。然無論如何，但凡君有所需，方塘恆在此處，靜候於君。
