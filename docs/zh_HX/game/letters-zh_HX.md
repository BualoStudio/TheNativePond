# 信紙

> [!NOTE]
> 此檔用以存錄所有於遊戲中出現之信紙。

> [!WARNING]
> 此檔內容未經評估與修訂，或存有違背價值觀之處。

1. 繁星點綴天空，清風拂過靜謐。於此寧靜之夜，萬千美好自會浮現於心。
2. 當君開始追光那一刻，君便成了光。
3. 君安。吾不知君為誰，亦無甚珍貴之禮相贈。然吾可贈君一朵小紅花，與一個微笑。願君日日歡欣~(◕ᴗ◕✿)！
4. 當一顆流星自天空墜落，非謂消亡，而謂其創造了獨屬於自己之美麗。
5. 待春風，待夏雨，待迎春開滿大地。待鳥聲，待蟲鳴，待繁星爍爍、夜穹之靜。待散學鈴歇、人聲鼎沸之歡愉；待列車抵站、笑淚交加之團聚。待煙花之響劃破雪夜之沉寂，人人相祝，緊緊相依。待世間一切美好降臨之頃，君我臉上，同露笑意。
6. 也許世上有五千朵與君相同之花，然惟君是那一朵獨一無二之玫瑰。——《小王子》
7. 幸福為何？其會調皮地躲於落葉堆裡，會於塘邊泛起陣陣漣漪，會於合歡樹之芽間生長，會被芳草間之蟋蟀傳遞，會於五文錢之冰棍上化開，會自燒烤攤之煙氣上升起，會悄悄地藏於君之心底，而出現於每個用心感知之瞬間。
8. 吾獨自佇立塘邊之際，總向塘中傾注己之低語。或水面能以廣闊之胸懷，容納世間所有思緒。
9. 再美麗之花，也曾只是一棵新芽。所有之美皆需等待，所有之綻放皆需時間。
10. 一片樹葉落下時，並非被春拋棄，而是於演奏秋之樂章。
11. 於時間之長河中，每個個體皆是一朵奔騰之浪花，無休無止地奔湧向前。人人皆無法抓住浪花，然記憶可以銘刻浪之聲。
12. 不必為擁抱藍天而長出翅膀，亦不必為擁抱大海而長出魚鰭。
13. 人們總是嚮往天上之太陽，卻時常忽略露間之月光。
14. 或許美好並非沒有殘缺，而是在殘缺中尋找碎片之美。
15. 於塘之對岸，是否有一人，與吾吹著同一陣晚風？
16. 數億年後，於宇宙之另一端，會不會有一位小孩，躺於草地上，望一片來自數億年前之星空，恰恰注視著此時數億年前之吾？
17. 世上只有一種英雄主義，那便是認清生活之真相後仍然熱愛生活。——羅曼·羅蘭
18. 生活仍在繼續，太陽仍會照常升起。明日，又是新之一天。
19. 旅人啊，不必為停滯不前而懊惱，整裝待發方能行得更遠。
20. 人一輩子皆有許多不順心之事，一件完了一件又來。故丁香結年年皆有。結，是解不完的；人生中之問題亦是解不完的，不然，豈不太平淡無味了嗎？——宗璞《丁香結》
21. 時間會將每一個珍貴之瞬間銘刻下來。正如樹之年輪，那是其生命之紀念。
22. 保持微笑。君看，當君微笑時，這片水塘亦在微笑著看君。
23. 浩瀚之宇宙中有不計其數之星星，當君抬頭仰望星空時，總有一顆星是獨屬於君之。
24. 生命本就是在無數奇蹟中創造的。假如有一天，君走到了「絕境」，吾相信君一定會書寫一段「生命之奇蹟」。
25. 若生活是無意義的，那麼不妨讓生活每一分每一秒，皆由君賦予意義。
26. 不要為一小片烏雲而煩惱。打開視野，等待君之是一整片廣闊之天空。
27. 於有些人看來，希望或只是一盞孤燈。然其所發之一絲微光，足以於黑夜中指引方向。選擇緊握希望，便是追求光明之第一步。
28. 正因有了落差，才有了河流奔騰之壯麗。
29. 未知常常是最使人擔心之事。然，確定又一成不變之生活，又有甚麼意思？使生活真正得以成為生活者，便是其富有魅力之未知性。
30. 與「一生」這漫長之時間單位相比，身邊之瑣屑都只是暫時。不必被一些小事桎梏，未來之路依舊很長。
31. 不必強迫自己開成玫瑰花，人人皆有獨屬於自己之一份豔麗。
32. 生命來到這世間，經歷了數億分之一或數萬億分之一之巧合。也就是說，君本就是這世間最珍貴之禮物。
33. 主角並不只是在台上綻放光彩之那一個，當君拼盡全力演繹自己之生活時，君同樣也是一位耀眼之主角。
34. 至少……夕陽很美，不是嗎？
35. 吾知曉，面對生活之考驗，仍堅持走到今天，是很不容易之事。君真的很勇敢。
36. 人人皆有得意或失意之時，正如天上之月亮，有時圓有時缺。然，圓缺之變化，不正是月亮獨特之美麗之處嗎？珍惜圓滿，亦不必苦於缺憾。
37. 人生本就是一場漫無目的之旅行，吾輩本不必到達目的地，體會旅途本身比追尋旅途之終點更重要。
38. 當蒲公英飛向遠方時，其並不知道自己將去往何方。然無論到哪裡，其都會努力生根發芽。
39. 有時，對自己寬容一些會更好。沒有必要甚麼時候都表現得很要強，不妨給自己留點空間，把自己拼好。
40. 坦然面對曾經之自己，然後與祂告別。這是成長之一環。
41. 白天之歡笑與淚水，都會於夢裡匯成一段新之故事。不妨把昨天拋在夢裡，今天又是嶄新之一天。
42. 情緒是潮水，其會來，亦會走。而君是岸，一直都在這裡。
43. 生物必刷題有言：縱天下盡棄君，然當記君身尚有數十億之細胞，僅為君而生。
44. 惟知幻想而不力行之人，終不能體會收穫果實之喜。
45. 志之堅定，乃性情中最要之力量源泉之一，亦成功之利器之一。無之，縱天才亦將於矛盾無定之迷徑中徒勞無功。
46. 青春如一只容器，滿載不安、躁動、青澀，與偶爾之瘋狂。
47. 同伴者，不必定要同行至終。某一段路上，彼所贈君之朗朗笑聲，便已足夠。
48. 無所期冀，失之亦不傷心，得之便是驚喜。
49. 障礙與失敗，乃通往成功最穩妥之踏腳石。肯研而用之，便能自失敗中養出成功。
50. 失金錢者，所損甚微；失健康者，所損甚巨；失勇氣者，所損一切。
51. 懼於自苦之人，已因己之恐懼而受苦。
52. 成功之信念，於人腦中之用，猶如鬧鐘，於君需要之際，喚君而起。
53. 過錯乃一時之憾，而錯過則為永世之憾！
54. 當走過曾經隱忍之歲月，再回首時，吾方知，昔日以為難以啟齒之往事，皆不過滄海一粟。生命予吾者，非是艱難，而是成長；是學得舉重若輕；是將昔日無法釋懷之種種過往，盡皆放下。
55. 所謂人間煙火，便是這樣一個時而溫暖、時而冷漠之詞；所謂人間，便是這樣一些時而光明、時而黑暗之刻。
56. 此世間，甚麼皆可安排，惟獨君之心。此世間，失卻誰都不可怕、不要緊，惟獨失卻君自己。往後尚有很漫長很漫長之路，都要一人走完，皆靠己身，憑己之力以竟之。此路之上，故事是昨日之瞬間，沿著長長之路，恍然如夢，直至永遠。
57. 此世間，不會因君之付出而必予回報，亦不會因君以何種方式待他人，便要求他人同等待君。人活於世，最難者，莫過於保持一份謙卑與平和；而此謙卑，源於內心之真誠與踏實之努力。
58. 他人皆於君所不見之處暗自努力；於君所見之處，彼等亦如君一般，顯出一副吊兒郎當之態，同君一樣會抱怨。惟君信此皆為真，故最後亦惟君一人，繼續不思進取。
59. 人人皆非君所見之那般。彼等一面是長著翅膀、純潔善良之天使，一面是持著夜叉、面目猙獰之惡魔。彼等心中之脆弱與膽小，彼等不願承認之虛榮與懦弱，皆藏於光鮮之下。彼等亦有潦倒之時，彼等亦曾見過人間之疾苦，彼等亦會於選擇之前猶豫，彼等亦曾愚蠢地放棄機會；彼等亦於對己之下屬橫眉冷對之際，驀然想起，昔日亦有人如此待己。
60. 吾輩所要面對之苦難與挫折，不會因吾輩遭遇夠多而減少；上天不會因君之悲慘而憫憐君，其只會安排一道又一道之難關，以磨煉君之意志。正如唐僧西天取經一般，欲取真經，便莫存返途之念；君除了一路苦撐到底，根本別無退路。
61. 對待生命，君不妨大膽冒險一些，因為好歹君終要失卻它。若此世間真有奇蹟，那只是努力之另一個名字。沒有人能拯救自己，到最後拯救君者，惟君自己。絕處逢生之喜，大難不死之慶，皆非君所想之「人品守恆」。於此世間面前，生活是無比重具體而煩瑣之藤蔓；君惟有從中體會酸甜苦辣，方知其最後之餘香。
62. 心情，乃一種感情之態。擁有了一份好心情，便也擁有了自信，繼而擁有了年輕與健康，便也擁有了對未來生活之嚮往，充滿期待。讓我輩擁有一份好心情罷，因為生活著，便是幸運與快樂。
63. 於歲月中跋涉，人人皆有自己的故事。看淡，心境方會秀麗；看開，心情方會明媚。倦時歇一歇，隨清風漫舞；煩時靜一靜，與花草凝眸；急時緩一緩，向自己微笑。
64. 生命之美，不在其絢爛，而在其平和；生命之動人，不在其激情，而在其平靜。惟平和，方見生命之廣大；惟平靜，方見生命之深遠。
