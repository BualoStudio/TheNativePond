# 信紙

> [!NOTE]
> 此檔用以存錄所有於遊戲中出現之信紙。

1. 繁星點綴天空，清風拂過靜謐。於此寧靜之夜晚，萬千美好自會浮現於心中。
2. 當君開始追光那一刻，君便成了光。
3. 君安。吾不知君為誰，亦無珍貴之禮相贈。然吾可贈君一朵小紅花，與一個微笑。願君日日歡欣~(◕ᴗ◕✿)！
4. 當一顆流星自天空墜落，非謂消亡，而謂其創造了獨屬於自己之美麗。
5. 待春風，待夏雨，待迎春開滿大地。待鳥聲，待蟲鳴，待繁星爍爍，夜空寧靜。待下課鈴響，人聲鼎沸之歡愉；待火車到站，笑淚交加之團聚。待煙花之響劃破雪夜之沉寂，人人相祝，緊緊相依。待世間一切美好降臨之頃，君我臉上，同露笑意。
6. 也許世上有五千朵與君相同之花，然惟君是那一朵獨一無二之玫瑰。——《小王子》
7. 幸福為何？其會調皮地躲於落葉堆裡，會於池塘邊泛起陣陣漣漪，會於合歡樹之芽間生長，會被芳草間之蟋蟀傳遞，會於五毛錢之冰棍上化開，會自燒烤攤之煙氣上升起，會悄悄地藏於君之心底，而出現於每個用心感知之瞬間。
8. 吾獨自佇立塘邊之際，總向池塘傾注己之低語。或水面能以廣闊之胸懷，容納世間所有思緒。
9. 再美麗之花，也曾只是一棵新芽。所有之美皆需等待，所有之綻放皆需時間。
10. 一片樹葉落下時，並非被春拋棄，而是於演奏秋之樂章。
11. 於時間之長河中，每個個體皆是一朵奔騰之浪花，無休無止地奔湧向前。人人皆無法抓住浪花，然記憶可以銘刻浪之聲。
12. 不必為擁抱藍天而長出翅膀，亦不必為擁抱大海而長出魚鰭。
13. 人們總嚮往天上之太陽，卻時常忽略露間之月光。
14. 或美好並非沒有殘缺，而是於殘缺中尋覓碎片之美。
15. 於塘之對岸，是否有一人，與吾吹著同一陣晚風？
16. 數億年後，於宇宙之另一端，會不會有一位小孩，躺於草地上，望一片來自數億年前之星空，恰恰注視此時數億年前之吾？
17. 世上惟有一種英雄主義，即認清生活之真相後，仍舊熱愛生活。——羅曼·羅蘭
18. 生活仍在繼續，太陽仍會照常升起。明日，又是新之一天。
19. 旅人啊，不必為停滯不前而懊惱，整裝待發，方能行得更遠。
20. 每個人一輩子都有許多不順心之事，一件完了一件又來。故丁香結年年皆有。結，是解不完的；人生中之問題亦是解不完的，不然，豈不太平淡無味了嗎？——宗璞《丁香結》
21. 時間會將每一個珍貴之瞬間銘刻下來。正如樹之年輪，那是其生命之紀念。
22. 保持微笑。君看，當君微笑時，這片水塘亦在微笑著看君。
23. 浩瀚宇宙中有不計其數之星，當君抬頭仰望星空時，總有一顆星是獨屬於君之。
24. 生命本就是在無數奇蹟中創造的。假如有一天，君走到了「絕境」，吾相信君一定會書寫一段「生命之奇蹟」。
25. 若生活是無意義的，那麼不妨讓生活每一分每一秒，皆由君賦予意義。
26. 不要為一小片烏雲而煩惱。打開視野，等待君之是一整片廣闊之天空。
27. 於有些人看來，希望或只是一盞孤燈。然其發出之一絲微光，足以於黑夜中指引方向。選擇緊握希望，便是追求光明之第一步。
28. 正因有了落差，才有河流奔騰之壯麗。
29. 未知常常是最令人擔心之事。然確定而一成不變之生活，又有何意趣？使生活真正得以成為生活者，正是其富有魅力之未知性。
30. 與「一生」這漫長之時間單位相比，身邊之瑣屑皆只是暫時。不必被一些小事所桎梏，未來之路依舊很長。
31. 不必強迫自己開成玫瑰花，每個人都有獨屬於自己之一份豔麗。
32. 生命來到這世間，歷經數億分之一或數萬億分之一之巧合。也就是說，君本就是這世間最珍貴之禮物。
33. 主角並不只是在台上綻放光彩之那一個，當君拼盡全力演繹自己之生活時，君同樣也是一位耀眼之主角。
34. 至少……夕陽很美，不是嗎？
35. 吾知曉，面對生活之考驗，仍堅持走到今天，實屬不易。君真的很勇敢。
36. 每個人都有自己得意或失意之時，正如天上之月亮，時圓時缺。然圓缺之變化，不正是月亮獨特之美麗之處嗎？珍惜圓滿，亦不必苦於缺憾。
37. 人生本就是一場漫無目的之旅行，吾輩本不必到達目的地；體會旅途本身，比追尋旅途之終點更重要。
38. 當蒲公英飛向遠方時，其並不知自己將去往何方。然無論到哪裡，其都會努力生根發芽。
39. 有的時候，對自己寬容一些會更好。沒有必要什麼時候都表現得很要強，不妨給自己留點空間，把自己拼好。
40. 坦然面對曾經之自己，然後與祂告別。此乃成長之一環。
41. 白天之歡笑與淚水，都會於夢裡匯成一段新之故事。不妨把昨天拋於夢裡，今天又是嶄新之一天。
42. 情緒是潮水，其會來，也會走。而君是岸，一直都在這裡。
43. 無論發生什麼，君心底仍有那二十億個熾熱之細胞，在為君跳動。
