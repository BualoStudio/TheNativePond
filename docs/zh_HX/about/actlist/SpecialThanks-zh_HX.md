# 特別致謝

- [@Minecraft](https://minecraft.net)  
	- Minecraft 乃《方塘》製作組之北辰，居其所而眾星拱之，吾輩心嚮往焉，奉為師法之楷模。  
	- Minecraft 啟吾輩「率性由心」之大道，為《方塘》自由至上之開發理念，導其先路。  

- [@Farmer's Delight](https://www.curseforge.com/minecraft/mc-mods/farmers-delight)  
	- Farmer's Delight 導《方塘》以療愈心神、從容徐行之幽致，令斯塘別具恬淡之氣。  
	- Farmer's Delight 循序漸進以炮製珍饌之諸般法度，皆為《方塘》庖廚之設，賜予妙悟。
