# 特別致謝

- [@Minecraft](https://minecraft.net)  
	- Minecraft 乃《方塘》製作組之北辰，亦吾輩所師法之楷模也。  
	- Minecraft 為《方塘》自由至上之開發理念，導其先路。  

- [@Farmer's Delight](https://www.curseforge.com/minecraft/mc-mods/farmers-delight)  
	- Farmer's Delight 為《方塘》治癒、從容之理念，啟其端緒。  
	- Farmer's Delight 中循序漸進以製美食等諸多設定，皆為《方塘》之相關設定啟其靈思。
