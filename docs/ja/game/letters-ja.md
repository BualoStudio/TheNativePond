# 手紙

> [!NOTE]
> このファイルは、ゲーム内に登場するすべての手紙を収録するためのものです。

1. 星々が空を飾り、清らかな風が静けさを吹き抜けていく。この穏やかな夜には、数えきれないほどの美しい想いが、自然と心に浮かんでくる。
2. 光を追い始めたその瞬間から、あなた自身が光になる。
3. こんにちは。あなたが誰かは知らないけれど、贈れるほど貴重なものも持っていない。でも、小さな赤い花と、笑顔ひとつだけは贈れるよ。毎日楽しく過ごしてね〜(◕ᴗ◕✿)！
4. 流れ星が空から落ちるとき、それは消えゆくことを意味しない。自分だけの美しさを生み出した証なのだ。
5. 春の風を待ち、夏の雨を待ち、レンギョウの花が大地を満たすのを待つ。小鳥のさえずりを待ち、虫の声を待ち、星々がきらめく夜空の静けさを待つ。授業の終わりのチャイムを待ち、人々の歓声に沸く楽しさを待ち、汽車が駅に着き、笑顔と涙の再会を待つ。花火の音が雪夜の静寂を切り裂き、人々が祝福し合い、寄り添い合うのを待つ。この世のすべての美しさが訪れるその瞬間、あなたと私の顔に、同じ笑みが浮かぶのを待っている。
6. 世の中にはあなたと同じ花が五千輪あるかもしれない。でも、あなただけが、そのたった一輪のバラなんだ。——『星の王子さま』
7. 幸せって何だろう？それは、いたずらに落ち葉の山のなかに隠れ、池のほとりにさざ波を立て、ネムノキの芽のあいだで育ち、草むらのコオロギに運ばれ、安いアイスキャンディーの上で溶け、屋台の煙のなかから立ちのぼり、静かにあなたの心の奥底に隠れていて、心を込めて感じるすべての瞬間に姿を現すもの。
8. ひとりで塘のほとりにいるとき、私はいつも自分の呟きを池のなかへ注ぎ込む。水面はその広い胸で、この世のすべての想いを抱きとめてくれるのかもしれない。
9. どんなに美しい花も、かつてはただの新芽だった。すべての美しさには待つことが必要で、すべての開花には時間が必要なのだ。
10. 一枚の葉が落ちるとき、それは春に見捨てられたわけではない。秋の楽章を奏でているのだ。
11. 時間という長い川のなかで、ひとりひとりは奔流する一つの波しぶきであり、絶え間なく前へと押し寄せる。誰も波しぶきをつかむことはできない。しかし記憶は、波の音を刻みつけることができる。
12. 青空を抱きしめるために翼を生やす必要はないし、海を抱きしめるために魚のひれを生やす必要もない。
13. 人々はいつも天上の太陽に憧れるけれど、露のなかの月明かりをしばしば見逃してしまう。
14. もしかしたら美しさとは、欠けのないことではなく、欠けたもののなかに、かけらの美しさを見つけることなのかもしれない。
15. 塘の向こう岸に、私と同じ夜風に吹かれている人がいるのだろうか？
16. 数億年後、宇宙の果てで、一人の子供が草の上に寝転がり、数億年前の星空を見上げて、ちょうどいま、数億年前の私を見つめている——そんなことがあるのだろうか？
17. この世の英雄主義はただ一つ。それは、人生の真実を見抜いたうえで、なお人生を愛することだ。——ロマン・ロラン
18. 生活は続いていくし、太陽はいつもどおり昇る。明日は、また新しい一日だ。
19. 旅人よ、立ち止まることを悔やむ必要はない。装いを整えてから出発すれば、より遠くまで行けるのだから。
20. 誰の人生にも思い通りにならないことはたくさんあって、一つ終わればまた次がやってくる。だからライラックの結び目は毎年できる。結び目は解ききれないものだし、人生の問題もまた解ききれない。そうでなければ、あまりに平淡で味気ないではないか。——宗璞『ライラックの結び目』
21. 時間は、かけがえのない瞬間のひとつひとつを刻みつけていく。木の年輪のように——それは、彼らの命の記念なのだ。
22. 微笑みを絶やさないで。ほら、あなたが微笑むとき、この池も微笑みながらあなたを見ているよ。
23. 広大な宇宙には数えきれない星がある。星空を見上げるとき、いつもあなただけの星が、一つだけあるのだ。
24. 命はそもそも、無数の奇跡のなかから生まれるものだ。もしある日、あなたが「絶望のどん底」に立たされたとしても、きっとあなたは「命の奇跡」という物語を紡ぐはずだと、私は信じている。
25. もし人生に意味がないのなら、人生の一分一秒に、あなた自身が意味を与えてみてはどうだろう。
26. 小さな暗雲ひとつで悩まないで。視野を広げれば、あなたを待っているのは、どこまでも続く広い空だ。
27. ある人にとって、希望はただの小さな灯りかもしれない。しかし、その灯りが放つ一筋の微かな光は、闇夜のなかで方向を指し示すのに十分だ。希望をしっかりと握りしめることを選ぶこと、それこそが光を追い求める第一歩なのだ。
28. 落差があるからこそ、河は奔流の壮麗さを生むのだ。
29. 人々が最も恐れるのは、しばしば未知のことだ。しかし、確かで何の変化もない人生に、いったい何の面白みがあるだろう？人生を本当に人生たらしめているのは、その魅力的な未知性なのだ。
30. 「一生」という長い時間の単位に比べれば、身の回りの些細なことは、すべて一時的なものだ。小さなことに縛られる必要はない。未来の道は、まだ長いのだから。
31. 無理にバラのように咲く必要はない。誰にでも、自分だけの華やかさがあるのだから。
32. 命がこの世に生まれるのは、数億分の一、あるいは数兆分の一という偶然を経てのこと。つまり、あなた自身が、この世で最もかけがえのない贈り物なのだ。
33. 主人公は、舞台の上で輝く者だけではない。あなたが全力で自分の人生を演じるとき、あなたもまた、眩しい主人公なのだ。
34. せめて……夕陽は美しい。そう思わない？
35. 分かっているよ。人生の試練に直面しながら、それでも今日まで歩き続けてきたのは、とても大変なことだったはず。あなたは本当に勇敢だ。
36. 誰にでも順風満帆のときもあれば、不遇のときもある。まるで空の月のように、満ちたり欠けたりする。しかし、その満ち欠けこそが、月ならではの美しさではないだろうか。満ちた月を大切にしながら、欠けた月を嘆く必要もない。
37. 人生はそもそも、目的のない旅だ。目的地にたどり着く必要はない。旅そのものを味わうことこそ、旅の終着点を追い求めることよりも大切なのだ。
38. タンポポが遠くへ飛んでいくとき、自分がどこへ向かうのか分かっていない。でも、どこへ行っても、しっかりと根を張り、芽を出すために努力するのだ。
39. 時には、自分に少し寛容になるほうがいい。いつだって強がる必要はない。自分に少し余白を残して、自分自身を組み立て直してみよう。
40. かつての自分をありのまま受け入れ、そして別れを告げる。それも成長の一部だ。
41. 昼間の笑い声も涙も、夢のなかで一つの新しい物語になる。昨日は夢のなかに置いてしまおう。今日はまた、真新しい一日だ。
42. 感情は潮のようなもの。やってきて、そして去っていく。でもあなたは岸辺。いつだって、ここにいる。
43. 何が起ころうとも、あなたの心の奥底では、20億個の熱い細胞が、あなたのために脈打っている。
