親愛なるプレイヤー：

気づけば、あなたはThe Native Pondで百日の時を過ごしていました。

あなたはThe Native Pondでたくさんのことを経験しました。雨に打たれたこともあれば、雨上がりの晴れ間を待ち望んだこともありました。長い待ち時間の末に針にかかった一匹の魚に興奮したこともあれば、舌先で花開くひと口の美味しさに歓喜したこともあります。時には塘のほとりを歩き回り、「さわやかな風が静かに吹き、水面は穏やかなまま」という静けさをじっと眺めていたこともあります。時にはあちこちを探索し、一輪の花、一枚の草の美しさを見つけ出していたこともあります。時にはただ静かに座って瞑想し、疲れ果てたけれど満ち足りた一日を噛みしめていたこともあります。

The Native Pondがあなたに百日の素晴らしさを届けられたこと、そして百時間の慰めを届けられたことを、私は誇りに思います。

もしかすると、もう一つの世界の生活は、The Native Pondでの生活ほど美しくないかもしれません。しかし、新しい一日の太陽が昇るとき、道端の花が咲くとき、風が林の間を抜けるとき、春の雨が大地にしとしとと降り注ぐとき、食べ物の温もりが口元によみがえるとき、道端の小さな猫がふと生活に飛び込んでくるとき、やわらかい芝生を踏みしめるとき、顔を上げて夜空の星を見るとき——そんなとき、The Native Pondの美しさを思い出し、生活への活力に、再び火が灯りますように。

未来、あなたはThe Native Pondに留まり続けるかもしれませんし、ただときどき顔を出すだけかもしれません。いつか永遠にThe Native Pondを離れることになっても、この塘にあなたの物語が刻まれたことを、私たちは喜ばしく思います。しかし、何があっても、あなたが必要とするとき、The Native Pondはいつだってここで待っています。
