## ✨ The Native Pondの意味とは？

現実の生活では、人々はいつもさまざまなタスクやプレッシャー、責任に追われています。それらはしばしば心身ともに疲れ果てさせ、方向感覚や自分自身の価値までも見失わせてしまいます。私たちは、そろそろ一つの水塘を切り開くときだと考えました——誰もがこの忙しない時代に、歩みを緩められる場所を。The Native Pondは、すべての人の心の避難所です。大きくはありませんが、あらゆる感情や心の内を包み込むには十分な広さがあります。そのために、私たちはThe Native Pondをユートピアと定義しました。The Native Pondでは、悪いことは何ひとつ存在せず、起こりもしません。それは、平和と愛と希望をのせた、心の給油所なのです。**The Native Pondが存在する意味は、誰もが現実のどんな困難や挫折、苦しみに直面したときにも、The Native Pondのなかでひとときの休息と癒やしを得て、より満ち足りた心持ちで再び生活に向き合えるようにすることです**。ゲームはプレイヤーに「これはただのゲームだ」と絶えず語りかけます。その目的は、プレイヤーがThe Native Pondにのめり込みすぎて、現実世界から逃げたり拒んだりすることを防ぐためです。

## 👟 The Native Pondはどのように運営されているのか？

私たちは気づきました——いまのゲームの多くは、毎日のログイン、クエストシステム、ダンジョン周回など、味気ないコンテンツであふれていると。プレイヤーに毎日長時間オンラインでいることを強要し、高強度の反復操作を強いられるこうした仕組みは、ずっと以前からゲームの本来の趣旨に反していると、私たちは考えます。ゲームとは、プレイヤーが楽しみ、くつろぐためのものであるべきです。ゲームメーカーがプレイヤーから搾取するための金儲けの道具ではありません。そのために、The Native Pond制作チームは約束します：**本作はソースコードをオープンソース化し、全プラットフォームで無料公開します。ゲーム内に広告は一切含まれず、いかなる形の有料DLCやマイクロトランザクションも含まれません**。私たちは、プレイヤーが求めているのは真に質の高いゲームであり、短期的な利益ばかりを追い求めてプレイヤーの気持ちを顧みない粗悪な商品ではないと信じています。
