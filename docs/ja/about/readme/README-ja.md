**The Native Pond** は、**Bualo Studio** が開発した非営利のヒーリングゲームです。

今、プレイヤーたちは終わりのないデイリーログイン、バトルパス、数値の詰め込み、ガチャへの不安に縛られています。私たちは、ゲームを時間どおりにログインしてこなす「負担」ではなく、ゲームへの最初の愛を取り戻してほしいと願っています。だからこそ、私たちのゲームは——**ログインなし・数値の強さなし・クエストやダンジョンなし**。スタミナバーも戦闘力も、強制される目標さえもない、小さな池です。ここで、**ゲームへの愛を、もう一度**。

## ✨ コア体験とゲームプレイ

*The Native Pond* は「クリックすれば手に入る」ファストフード的なデザインを拒否します。私たちは、生活の中のリアルな手触りを、リアルな再現プロセスを通じて、極限までシンプルな画面の下に表現しました。

### 🎣 没入感あふれるリアルな釣り

これはスペースキーを押せば魚が釣れるアーケードミニゲームなどではありません。私たちは本物の釣りの流れを忠実に再現することにこだわっています：

- **自分で作る餌**：ゲーム内の雑貨屋で基本の餌を買い、天気や狙う水域に合わせて、少しずつ水を加え、こね、寝かせ、撒き餌を打つ——そんな工程を自分の手で行います。
- **リアルな待ち時間**：餌をつけ、竿を振り、水面のさざ波のわずかな変化と浮きの沈み込みを見極めて、竿を上げる最高のタイミングを掴みます。
- **特別なコレクション**：時には釣り上げられるのは魚ではなく「コレクション」かもしれません。

### 🍳 暮らしの匂いあふれる自由な料理

釣りのほかに、ゲームには現実とまったく同じ手順の料理システムが組み込まれており、サイバー空間に生活の実感を満たします：

- **本格的な手順の分解**：素朴な麺料理「陽春麺」を一碗食べたい？まず小麦粉を買って、まな板の上で自分で水を加え、こね、寝かせて、麺を延ばすところから始まります。
- **火加減とタイミング**：水を汲み、火をつけ、お湯が沸くのをじっくり待ってから麺を入れます。どの工程も省略はできません。食材が自分の手の中で少しずつ形になっていく、確かな手応えを感じてください。
- **完全に自由な料理**：「レシピ」に忠実に従うのもよし、すべてのルールを無視して自由に食材を組み合わせるのもよし。嬉しい美味しさも、ダーク料理も——ここにあるのは楽しさだけ。罰則はありません。

### 🥬 のんびり癒やされる畑仕事の時間

ゲームには畑仕事の遊び方もあり、すべてのプレイヤーが自分の手で小さな世界を開拓できます：

- **種まき**：作物の育ちやすい季節になれば、畑を耕し、種をまき、水をやり、肥料をあげて、作物の成長を支えます。
- **成長**：環境が整えば、作物はすくすくと育ちます。手をかけすぎる必要はありません。たまに気にかけるだけでいい——そんな気楽さと楽しさが、畑仕事の時間にはあります。
- **収穫**：作物が実れば、収穫のときです。ワンクリックで済む高速収穫ではなく、本物の収穫／刈り取りの流れを再現することで、収穫の喜びと達成感をしっかりと味わえます。

### 🎨 極みのミニマル・ビジュアル美学

- **大きな色面とフラットデザイン**：余計なテクスチャを排し、純粋な SVG ベクターの色面だけで画面を構成します。
- **UIレスデザイン**：ボタンや課金入口が画面いっぱいに並ぶことはありません。画面は清らかで控えめ——スクリーンは水面に委ねられます。
- **純粋な放空**：ノンリニアなアニメーションが池の水をそっと「呼吸」させます。長い待ち時間の中で、時間をあなたの頭の中に返しましょう。

## 🛠️ 技術スタックとアーキテクチャ

軽量化・クロスプラットフォーム・コミュニティの参加のしやすさを実現するため、本プロジェクトは以下の技術基盤を採用しています：

- **基盤エンジン**：*The Native Pond* のために私たちが開発した [**Icelet**](https://github.com/BualoStudio/Icelet) ゲームエンジンをベースに開発されています。

> [!WARNING]
> やむを得ない事情により、Icelet の開発は終了しました。現在、The Native Pond に技術支援を提供するための新しいゲームエンジンや実装方法を模索しています。詳細は Icelet 開発終了のお知らせをご覧ください：[「突然の終わり、まるで青春のように」](https://github.com/BualoStudio/Icelet/releases/tag/TheEnding)。

- **レンダリング方式**：HTML5 ネイティブレンダリング。驚くほど軽量で、あらゆるローエンド端末でもなめらかに動作します。
- **アセット形式**：多くのアートアセットは SVG 形式を採用。あらゆる解像度でもエッジがシャープに保たれます。

## 🤝 コミュニティへの参加

*The Native Pond* は私たちだけの作品ではありません。疲れたすべてのプレイヤーにとっての「心の充電ステーション」になれるよう願っています。ゲーム開発やコードに詳しくなくても、この小さな池に、あなたもひとつのレンガを加えることができます！

> [!TIP]
> 参加前に、ぜひ私たちの [**コントリビューションガイド**](https://github.com/BualoStudio/TheNativePond/blob/main/.github/CONTRIBUTING.md) を読み、[**行動規範**](https://github.com/BualoStudio/TheNativePond/blob/main/.github/CODE_OF_CONDUCT.md) を守ってください。

以下のような形式の Issue を心から歓迎します：

1. **記憶の欠片の投稿**：ゲームのための心に響く一文を書く、あるいは時代の空気を感じさせる思い出の短い文章を投稿してください。
2. **故郷のレシピの投稿**：新しいレシピをデザイン（例：本場の熱乾麺を一碗、どう作るか）し、その手順を分解して紹介してください。
3. **ゲームの不具合の報告**：特定の状況で発生するゲームの問題・バグ・エラーを報告してください。解決策があればなお歓迎です。

## 🌐 ローカライズ

[**ローカライズ対応状況**](https://github.com/BualoStudio/TheNativePond/blob/main/docs/ja/about/l10nteam/LocalizationSupportStatus-ja.md) に、現在公式にサポートされている言語とその対応状況をまとめています。

*The Native Pond* を世界中のプレイヤーに遊んでもらいたいと考えています。ゲームをあなたの言語に翻訳するお手伝いをしてみませんか：

1. このリポジトリを Fork します。
2. 言語ファイルを探します（`/lang/` ディレクトリ内にあります）。
3. 翻訳を追加または更新します。
4. [**Pull Request**](https://github.com/BualoStudio/TheNativePond/pulls) を送信します。

> [!TIP]
> The Native Pond のローカライズは、あなたのような多くのボランティアによって支えられています。ぜひ [**ローカライズ謝辞リスト**](https://github.com/BualoStudio/TheNativePond/blob/main/docs/ja/about/l10nteam/LocalizationTeam-ja.md) をご覧ください。

> [!TIP]
> 開発サイクルや労力・リソースの配分などの事情により、翻訳の100%の正確さは保証できません。専任のローカライズチームがいないため、一部の言語は AI や機械翻訳によるもので、必ずしも正確とは限りません。プレイ中に翻訳の問題を見つけた場合は、上記の方法で [**PR を送信**](https://github.com/BualoStudio/TheNativePond/pulls) するか、[**Issue を投稿**](https://github.com/BualoStudio/TheNativePond/issues) してください。
