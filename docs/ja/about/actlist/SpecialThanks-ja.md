# 特別な感謝

- [@Minecraft](https://minecraft.net)  
	- Minecraft は The Native Pond 制作チームの灯台であり、私たちの学びの手本です。  
	- Minecraft は The Native Pond の「自由至上」の開発理念に道しるべを与えてくれました。  

- [@Farmer's Delight](https://www.curseforge.com/minecraft/mc-mods/farmers-delight)  
	- Farmer's Delight は The Native Pond のヒーリング系・スローライフといった理念に導きを与えてくれました。  
	- Farmer's Delight の「段階を追って料理を作る」など数多くの設定が、The Native Pond の関連設定にインスピレーションをもたらしてくれました。
